# Personal Website

Portfolio site for Anika Hakim, hosted on GitHub Pages.

## Preview locally

```sh
cd ~/personal-website
python3 -m http.server 8000
```

Open http://localhost:8000 in a browser.

## Publish

Push `main` to GitHub, then enable Pages from `main` / root.

## Edit

- `index.html` — content
- `styles.css` — styling
- `script.js` — footer year
